# Portfolio Web Responsivo

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas com o objetivo de aplicar conceitos de HTML, CSS e JavaScript na construção de uma interface responsiva.

## Status

✅ Projeto concluído

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Menu responsivo
- Navegação por seções
- Cards informativos
- Layout adaptável
- Simulador de orçamento
- Estrutura de portfólio

## Estrutura do Projeto

```text
assets/
├── css/
├── imagens/
├── js/

index.html
```

## Como Executar

1. Clone o repositório
2. Abra o arquivo `index.html`
3. Navegue pela aplicação diretamente no navegador
